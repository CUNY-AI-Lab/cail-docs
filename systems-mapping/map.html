The Map

Place items where the case supports them, then describe the relationships a reader should follow.

Items and Relationships

Select an item to edit Label in the Notebook, or select a connection to edit Relationship. Choose Save to apply the wording or Cancel to restore the saved text. Enter saves; Escape cancels. Moving focus or selecting another item does not save a draft. The same controls appear in suggestion Details.

Labels follow the item’s existing level. Micro relationships accept a verb or phrase; Exo relationships use the available decision-path choices. Invalid drafts leave the saved wording intact and show what needs revision. Saved wording updates any matching suggestion, and renaming an item updates its name in connected relationships.

An item’s level is fixed once it is mapped. To correct it, remove the item and add it at the appropriate level. You can still identify its settings and record evidence for the claim it makes. Connections also retain details about frequency, duration, direction, conditions, and change over time.

Drag items to arrange the map. The project saves their positions. Each ring shows the current level's items in color and retains earlier work, with Micro in teal, Meso in amber, Exo in plum, and Macro in ink. Open Map tools → Map key to read the line styles. Solid arrows show direct relationships, while dotted lines mark scope and membership.

List View

When you want to inspect labels or find an incomplete relationship, open Map tools → List. The table shows each item's level and settings alongside relationships and their verbs. You can review the same map without navigating the canvas, including when you use a keyboard or screen reader.

Map Check

Use Map Check when you want another reading of an item or connection you have already mapped. Open its editing details and choose Check this item or Check this connection. The course model returns at most four short notes tied to map IDs. Choose a note to highlight its target on the canvas.

A check leaves the map unchanged and follows the course guidance and limits used for memo review. Read each note against the evidence you recorded. If the model questions a relationship, return to its source passage before revising. If it proposes an item the evidence does not support, record that overreach for discussion.

Layout and Undo

Saving a label or relationship keeps node positions and the current view. The text’s card may resize. Use Arrange map to recalculate the arrangement, Fit map to refit the view, or move an item using its updated label size.

Arrange map places items automatically within their rings. Use Ctrl/Cmd+Z to undo moves and arrangements from the current visit. The app preserves evidence and label edits made afterward because layout undo applies to positions.

Fit map brings every visible item, connection label, and relationship field into the window. It fits the work on the map and leaves empty ring areas outside the view when needed.

Dependencies

The app blocks removal, or changing a Micro setting to a non-setting type, while active relationships, memberships, or scopes depend on it. Resolve the listed references first, then retry the change. Review the dependent work before removing its reference.
